# HR Attrition & Retention SQL Analysis

## Overview
Exploratory Data Analysis (EDA) performed on 1,470 employee records (IBM HR Attrition dataset) to identify retention risks, departmental turnover rates, and compensation trends.

## Tech Stack
* **Language:** SQL (SQLite / ANSI SQL)
* **Dataset:** IBM HR Analytics Employee Attrition & Performance

## Key Findings
1. **Departmental Risk:** High attrition concentration identified within specific operational units.
2. **Work-Life Drivers:** Employees working overtime exhibit significantly higher turnover rates compared to non-overtime peers.
